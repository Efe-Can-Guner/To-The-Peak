## TO THE PEAK
A 2D platformer/climbing built in Unity where player jumps in the never ending sky

To The Peak is a casual arcade game inspired by Color Switch. Players click/tap to jump and use horizontal movement to 
steer around obstacles as they climb. The gameplay is simple and reflex-based — easy to pick up, (will be) hard to master.

## FEATURES
* Very basic movement controls.
* Never-ending obstacles.
* Cozy atmosphere

## CONTROLS
Jump--MouseButton1
MoveLeft/Right--A/D

## BUILT WITH
Unity-Game Engine
C#-Scripting
